# Procesiukas

Statinė svetainė (HTML, CSS, JS) be priklausomybių ir be build žingsnio.

## Kontaktas
Visų mygtukų „Rezervuoti pokalbį“ nuoroda nustatoma vienoje vietoje — `CONTACT_URL` faile `main.js`.
Šiuo metu ten laikinas adresas; pakeiskite į tikrą el. paštą (`mailto:`) arba rezervacijos nuorodą.
